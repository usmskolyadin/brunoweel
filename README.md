# Бруновиль

Одностраничный прототип загородного отеля для собак на Django и Tailwind CSS. Выбрана игривая концепция с мультяшными формами и разноцветными пастельными акцентами.

## Запуск

Установить зависимости:

```powershell
python -m pip install -r requirements.txt
npm install
```

В первом терминале собрать стили (или оставить наблюдение за изменениями):

```powershell
npm run build:css
```

Во втором терминале запустить Django:

```powershell
python manage.py migrate
python manage.py runserver
```

Открыть `http://127.0.0.1:8000/`. Админка доступна по адресу `/admin/`; для входа нужно создать администратора командой `python manage.py createsuperuser`.

## Примечание

Фотографии загружаются с Unsplash и используются только как временные визуальные заглушки. Контактные данные и адрес также демонстрационные. Перед публикацией замените их на реальные, настройте `SECRET_KEY`, `DEBUG` и `ALLOWED_HOSTS`.
